## 🌌 Sobre o projeto

**Space Survivor** é um jogo de sobrevivência espacial desenvolvido em Python com a biblioteca Pygame.

O objetivo é sobreviver aos meteoros, derrotar chefes poderosos, resgatar personagens e desbloquear novas naves ao longo da partida.

O projeto foi desenvolvido como uma forma de praticar programação, lógica, orientação a objetos e desenvolvimento de jogos com Python.

## 🎮 Funcionalidades

- 🚀 Diferentes naves jogáveis.
- 👾 Chefes com aparências, acessórios e ataques diferentes.
- ☄️ Meteoros de diferentes tamanhos e resistências.
- ❤️ Sistema de vidas com limite de 20 por jogador.
- 🛡️ Power-ups de escudo, tiro rápido e vida extra.
- 🧑‍🚀 Sistema de resgate de personagens.
- 🔓 Naves desbloqueáveis por pontuação e conquistas.
- 👥 Modo Solo e Cooperativo.
- ⌨️ Configuração personalizada de teclas para os dois jogadores.
- 🔄 Possibilidade de reiniciar a partida.

## 🕹️ Controles padrão

| Ação | Jogador 1 | Jogador 2 |
|---|---|---|
| Mover para cima | W | ↑ |
| Mover para baixo | S | ↓ |
| Mover para esquerda | A | ← |
| Mover para direita | D | → |
| Atirar | Espaço | Ctrl direito |
| Escudo | E | Shift direito |
| Tiro rápido | Q | Alt direito |
| Vida extra | H | Enter |

**Importante:** as teclas podem ser personalizadas dentro do menu de configurações.

## 👾 Chefes

O jogo possui diferentes chefes, cada um com características próprias:

- **Shadow:** chefe com chifres.
- **Destroyer:** chefe equipado com canhões.
- **Nemesis:** chefe com asas.
- **Titan:** chefe com armadura.
- **Overlord:** chefe com coroa.

Cada chefe apresenta uma dificuldade e uma quantidade de vida diferentes.

## 💻 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/space-survivor.git
```

### 2. Entre na pasta

```bash
cd space-survivor
```

### 3. Instale o Pygame

```bash
pip install pygame
```

### 4. Execute o jogo

```bash
python main.py
```
